*Задания 2–4*

У каждой задачи есть ID, название, отметка о выполнении и приоритет. Наборы задач лежат в `data.js`, функции для работы с ними — в `task-service.js`, а запуск двух сценариев и вывод — в `main.js`. При изменении задачи создаётся новый массив и копия этой задачи.

*Задание 5. Общий сценарий*

| Шаг | Ожидаемый прогресс | Что получилось (всего / выполнено / осталось) |
| --- | --- | --- |
| Начало | 50.0% | 4 / 2 / 2, 50.0% |
| Добавила 20 | 40.0% | 5 / 2 / 3, 40.0% |
| Отметила 4 выполненной | 60.0% | 5 / 3 / 2, 60.0% |
| Переименовала 10 | 60.0% | 5 / 3 / 2, 60.0% |
| Удалила 7 | 75.0% | 4 / 3 / 1, 75.0% |
| Повторно добавила 20 | Ошибка, 75.0% | Задача с ID 20 уже существует. 4 / 3 / 1, 75.0% |

Остались задачи 1, 4, 10 и 20. Из них не выполнена только 20. Исходный список сохранился.
